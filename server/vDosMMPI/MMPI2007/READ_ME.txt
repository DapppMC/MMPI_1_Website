    Petunjuk Pemakaian :

        1. Untuk pemakaian dari floppy drive :

           Sebelum mulai menggunakan aplikasi ini, anda perlu melakukan
           2 (dua) hal penting :

           a. Pastikan bahwa PC-DOS anda mampu membuka sampai 20 file
              bersama-sama. 

              Jika anda tidak yakin, pastikan disket PC-DOS anda memiliki
              file CONFIG.SYS yang memuat pernyataan :

                        files=20

              Jika disket PC-DOS anda tidak memiliki file tersebut,
              lakukanlah hal-hal berikut ini :

                - masukkan disket PC-DOS anda di drive A:

                - dari prompt A:\> berikanlah perintah :
                        copy con config.sys [enter]
                        files=20 [enter]
                        buffers=20 [enter]
                        [F6] [enter]

                - tekan tombol [Ctrl] [Alt] [Del] bersama-sama.


           b. Salinlah file COMMAND.COM dari disket PC-DOS anda ke 
              dalam disket aplikasi ini.



        2. Untuk pemakaian dengan hard disk :

           Aplikasi ini dilengkapi dengan file kunci yang tersembunyi
           dalam disket aslinya.

           Untuk menjalankan aplikasi ini dari hard disk, salinlah semua
           file dalam disket ini ke dalam hard disk anda. 

           Namun demikian, setiap kali dijalankan anda harus memasukkan
           disket aplikasi ini ke dalam drive A: terlebih dahulu,
           agar aplikasi dapat menemukan file kuncinya.


        
        3. Menempatkan data di dalam hard disk :

           Aplikasi ini memungkinkan anda untuk menyimpan data
           di dalam hard disk, baik drive C: ataupun D:.      

           a. Jika perlu buatlah sub-direktori khusus untuk menyimpan
              data anda, misalnya :

                C:\> MD \MMPI 

           b. Lakukanlah 'log-in' ke dalam sub-direktori data anda sebelum
              anda menjalankan aplikasi ini, misalnya :

                C:\> CD \MMPI

                C:\MMPI> A:

                A:\> m graph



        4. Jika anda memiliki drive A: untuk high capasity (1.2 MB) :

           Sebaiknya anda menukar identitas drive A: menjadi drive B:
           dan sebaliknya. Dengan demikian anda dapat menggunakan
           drive B: (360 KB) sebagai drive A:, dan sebaliknya.
           Penukaran harus dilakukan sebelum anda menjalankan aplikasi
           ini seperti lazimnya.

           Hal ini dapat dilakukan dengan memanfaatkan utility
           ASSIGN.COM dari disket PC-DOS anda, lakukanlah :

                A:\> assign a=b b=a
